# Resume Matcher AI

🚧 Coming soon — Week 2 project 🚧

An AI-powered tool that compares a resume against a job description, scores the match, and highlights missing keywords using NLP-based text similarity.

**Tech stack (planned):** Python · scikit-learn · Streamlit

## What it does
User gives resume + JD, app returns a match score + keywords to add to improve the match.

## Core features
1. Upload/paste resume + job description
2. Match score (%) based on text similarity
3. Missing keywords, ranked by priority — not a random list
